Origin story

Named for exploration.

The name MavenJS is inspired by NASA’s MAVEN mission to Mars: Mars Atmosphere and Volatile Evolution. Where the mission explores a planetary environment, MavenJS helps developers explore and manipulate the web environment efficiently.

Its focused API also draws inspiration from jQuery’s approachable model for traversal, events, and interface behavior.
